# OZON 售价计算器（CEL 运输费估算）

一个简洁的中文网页计算器，用于估算 OZON 商品售价、利润率，并按配置的 CEL 资费规则筛选可能适用的运输线路。

## 功能

- 输入商品成本、目标利润率、重量
- 可调整平台佣金、贴单费和 CNY/RUB 汇率
- 可输入包装尺寸，用于检查部分线路的尺寸和体积重限制
- 展示估算售价、运费、预计利润及利润率
- 纯静态网页，无需安装依赖或后端服务

## 本地运行

1. 下载或解压本项目。
2. 使用浏览器打开 `index.html`。
3. 修改输入参数并点击“计算售价与运输方式”。

也可以将本项目部署到 GitHub Pages、Cloudflare Pages 或其他静态网站托管服务。

## 重要说明

- 本项目当前为估算工具，不是 CEL 或 OZON 官方产品，也不保证承运商实时可报价。
- 汇率是可编辑的示例值，使用前请更新为实际结算汇率。
- 运输线路费率、重量范围、货值档位、尺寸限制及附加费应在使用前与最新的 CEL 资费文件核对。请勿将示例或尚未核验的规则当作正式报价。
- OZON 平台费率、尾程配送费、标签费等可能因账号、品类、国家、活动和时间变化，请按自己的实际规则调整。
- 目前的版本没有自动联网更新汇率或承运商资费。
